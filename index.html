1Location: one prompt, not two FIXED · 0bb939b small
What was wrongThe photograph panel offered “Add a location tag (optional)” over a block holding the template's capture fields — and on every survey on the site one of those fields, location, is required, showing “Required” and “Not yet completed”. The same control contradicted itself, and nothing said how the optional tag and the required location related.
What I didThe block now describes what it holds, and one line under it says what the values are for: they are stamped on each photograph added from there and are what the report reads as the location for each finding. A template with no required field still reads as optional.

2The report header stops printing the same words twice FIXED · 1565772 small
What was wrongEvery report raised from a template carries the template name inside its own title. The cover printed that same name again as an eyebrow above the title, so the header read “SNAG IDENTIFICATION & REMEDIAL SCHEDULE” stacked on “Snag identification & remedial schedule — 6 Oct 2026”.
What I didOne rule, in src/lib/report/letterhead.ts: if the title already opens with the template name, the eyebrow is suppressed. A title somebody typed (“13 Bruton Street — photo update”) does not name the template, so the eyebrow stays — which is also why a report issued before the relabel still shows the current template name. Applied to both covers and to the report workspace header, all three of which printed it. Six tests cover it.

8Sign-in emails still go out on a shared sender NEEDS YOU needs a decision
What's wrongReport emails are properly authenticated through Resend (SPF, feedback MX and DKIM all present on instructbrain.com). Sign-in emails are not: there is no notify. sending domain, so they run on the default sender with its hourly cap — the likely cause of Lovable’s “some users may see errors sending messages”.
Two routes(a) Lovable’s own email feature — paid plans only, DNS handled for you. (b) Point Supabase Auth’s SMTP at Resend — your auth already lives in your own Supabase project, the free tier covers it, and you already have the Resend account. I recommend (b): it costs nothing.
