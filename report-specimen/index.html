What was wrong

0headlines on 18 items
0contents pages
3section headings, for 22 pages
1item torn across a page break

Every finding already carries a short title, written and stored. The issued PDF never printed it, so eighteen items read as a flat run of prose behind bare numbers — 17, 18, 15, 8, 6 — grouped by severity but never sectioned, and never listed.

What changes

  1. Print the title that already exists Every finding has a one-line snag title. It becomes the headline of the item, with the full description underneath it. This is the single biggest change.
  2. Add a schedule of items One row per item: number, title, trade, severity, and the photograph and pin it refers to. Without it, finding item 5 means reading 22 pages.
  3. Label the sections, worst first The items are already grouped; the grouping is just invisible, and it runs cosmetic first. Make the headings explicit and lead with performance.
  4. Keep each record whole Reserve the whole item before drawing it, so a heading never lands on one page and its photograph and pin on the next.
  5. State the photograph and pin in words "Photograph 6, pin 1" as a chip on the item, and as a column in the schedule, so the pin is traceable without hunting the photograph pages.
  6. Offer the by-trade view The product already builds this grouping. Printed, it is the sheet a site manager hands to each subcontractor.
